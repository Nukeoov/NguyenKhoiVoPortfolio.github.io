Power BI / Business Intelligence Project

Revenue Analysis Dashboard

Sales Performance | Revenue Analytics | Business Intelligence

Project Overview

Developed an interactive Power BI revenue analysis dashboard to evaluate retail sales performance across products, stores, regions, and reporting periods from 2020 to 2022. Integrated transaction-level sales data with dimensional tables, implemented DAX measures for revenue, sales targets, and year-over-year comparisons, and designed dynamic reporting using field parameters. The dashboard enables users to monitor revenue performance, identify underperforming business areas, compare actual results against targets, and support data-driven decisions.

Analysis & Business Insights

What I Built

  • Data Integration: Combined sales transactions, customer, product, store, promotion, date, and sales plan data into Power BI.
  • Data Modeling: Built relationships between fact and dimension tables to support cross-filtering and consistent KPI calculations.
  • Revenue KPIs: Created DAX measures for actual revenue, planned revenue, customer counts, order counts, and product quantities.
  • Time Intelligence: Developed year-over-year, monthly, and YTD calculations to evaluate sales trends.
  • Dynamic Analysis: Implemented field parameters to switch reporting metrics without creating separate pages.
  • Performance Reporting: Built revenue and product-mix charts, monthly trends, and store-manager performance comparisons.
  • Interactivity: Added year filters, promotion slicers, toggle selections, and conditional formatting.

Insights & Recommendations

Key Insights

  • Revenue: VND 5.90 billion in 2022, compared with a target of VND 6.43 billion.
  • Target Achievement: Revenue reached 92% of plan, approximately VND 0.53 billion below target.
  • YoY Growth: Revenue declined approximately 15% versus the previous year.
  • Regional Performance: Cầu Giấy contributed the largest revenue share shown (27%), followed by Hai Bà Trưng (19%).
  • Product Mix: Household goods represented approximately 66% of revenue, the largest product category.

Recommendations

  • Investigate sales declines across periods with the largest negative YoY variance.
  • Prioritize underperforming stores and managers for performance reviews.
  • Analyze product categories contributing to revenue declines before adjusting promotions.
  • Use actual-versus-target comparisons to identify where corrective actions are needed.

Data Modeling & Relationships

Designed a star-schema-oriented Power BI data model centered on fact_sales, with related customer, product, store, promotion, and date dimensions. The additional fact_sales_plan table supports actual-versus-target analysis through shared reporting dimensions. The model also contains a calculated summary table, a field parameter table, and an organized measures table.

Sales Fact Table

fact_sales stores transactions, sales amounts, quantities, order dates, and dimension keys.

Sales Plan Fact Table

fact_sales_plan contains planned revenue by period and store, supporting target achievement analysis.

Field Parameters

A disconnected selection table enables dynamic switching between revenue, products sold, orders, and customers.

Modeling Approach

  • Connected the sales fact table to customer, product, promotion, store, and date dimensions.
  • Used one-to-many relationships for dimension-based filtering of transactional records.
  • Connected the sales plan table to shared dimensions to enable planned-versus-actual reporting.
  • Created a calculated table for product-category aggregation using DAX SUMMARIZE.
  • Organized reusable calculations in the _Measures table.

DAX Calculations & Dynamic Reporting

Developed reusable DAX measures to evaluate revenue performance, calculate year-over-year changes, measure sales target achievement, and support dynamic dashboard interactions.

01. Total Revenue

Calculates total sales revenue from fact_sales. Serves as the primary KPI and foundation for comparisons. 

Doanh Thu =
SUM(
    fact_sales[sales_amount]
)

02. Sales Target

Aggregates planned sales values from fact_sales_plan. Used for actual-versus-target performance reporting. 

Doanh Thu Kế Hoạch =
SUM(
    fact_sales_plan[sales_plan]
)

03. Target Achievement Percentage

Measures how much of the planned revenue has been achieved. DIVIDE handles zero-denominator situations safely. 

% Tiến Độ Kế Hoạch Doanh Thu =
DIVIDE(
    [Doanh Thu],
    [Doanh Thu Kế Hoạch],
    0
)

04. Previous Year Revenue

Retrieves revenue for the comparable period in the previous year using time-intelligence functions. 

Doanh Thu Cùng Kỳ Năm Ngoái =
CALCULATE(
    [Doanh Thu],
    SAMEPERIODLASTYEAR(dim_date[date])
)

05. Year-over-Year Revenue Growth

Calculates the percentage change in revenue versus the same period last year. Used in KPI cards and performance comparisons. 

% Tăng Trưởng So Với Cùng Kỳ =
DIVIDE(
    [Doanh Thu] -
    [Doanh Thu Cùng Kỳ Năm Ngoái],
    [Doanh Thu Cùng Kỳ Năm Ngoái],
    0
)

06. Year-to-Date Revenue

Calculates cumulative revenue from the beginning of the year through the selected date. Useful for monitoring annual performance trends. 

Doanh Thu Lũy Kế Năm =
TOTALYTD(
    [Doanh Thu],
    dim_date[date]
)

07. Order, Customer & Product KPIs

Creates three operational measures that allow the dashboard to compare revenue with transaction volume, customers, and units sold. 

Số Đơn Hàng =
DISTINCTCOUNT(
    fact_sales[order_number]
)

Số Khách Hàng =
DISTINCTCOUNT(
    fact_sales[customer_key]
)

Số Sản Phẩm Bán =
SUM(
    fact_sales[order_quantity]
)

08. Revenue Share by Product

Removes product-level filters to calculate total revenue and then evaluates each product category's contribution to the overall result. 

Doanh Thu Tất Cả Sản Phẩm =
CALCULATE(
    [Doanh Thu],
    ALL(dim_product)
)

% Tỷ Lệ Doanh Thu Nhóm Sản Phẩm =
DIVIDE(
    [Doanh Thu],
    [Doanh Thu Tất Cả Sản Phẩm]
)

09. Dynamic Field Parameter

Creates a field parameter that lets users switch between revenue, product quantity, orders, and customer count using the same chart layout. 

Parameter = {
    (
        "DOANH THU",
        NAMEOF('_Measures'[Doanh Thu]),
        0
    ),
    (
        "SỐ SẢN PHẨM",
        NAMEOF('_Measures'[Số Sản Phẩm Bán]),
        1
    ),
    (
        "SỐ ĐƠN HÀNG",
        NAMEOF('_Measures'[Số Đơn Hàng]),
        2
    ),
    (
        "SỐ KHÁCH HÀNG",
        NAMEOF('_Measures'[Số Khách Hàng]),
        3
    )
}

10. Dynamic Parameter Value

Uses the selected parameter to dynamically return the corresponding measure. Enables flexible reporting without duplicating visuals. 

Parameter value =
VAR selection =
    MAX(Parameter[Parameter])

RETURN
IF(
    selection = "DOANH THU",
    [Doanh Thu],
    IF(
        selection = "SỐ SẢN PHẨM",
        [Số Sản Phẩm Bán],
        IF(
            selection = "SỐ ĐƠN HÀNG",
            [Số Đơn Hàng],
            [Số Khách Hàng]
        )
    )
)

11. Calculated Product Summary

Uses SUMMARIZE to create an aggregated table by product category, containing revenue and order counts. Useful for product-level performance analysis. 

Calculated Table =
SUMMARIZE(
    dim_product,
    dim_product[product_category],
    "sales", [Doanh Thu],
    "order", [Số Đơn Hàng]
)
