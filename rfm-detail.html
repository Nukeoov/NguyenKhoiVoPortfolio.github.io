Power BI / Data Analytics Project

Customer Segmentation Analysis Dashboard

RFM Analysis | Customer Analytics | Business Intelligence

Project Overview

Developed an interactive Power BI dashboard to analyze customer purchasing behavior using Recency, Frequency, and Monetary (RFM) analysis. Integrated sales and customer data through a dimensional data model, developed DAX calculations to measure purchasing behavior, and classified customers into actionable segments. The dashboard enables customer-level analysis, demographic filtering, and segment comparisons to support targeted marketing and customer retention strategies.

Goal

Identify customer segments, evaluate purchasing behavior, and support targeted retention and marketing strategies.

Deliverable

An interactive RFM dashboard with customer segments, scoring distributions, detailed customer reporting, and demographic filters.

Analysis & Business Insights

What I Built

  • Data Integration: Imported sales, customer, product, store, date, and promotion tables into Power BI.
  • Data Modeling: Established one-to-many relationships between fact and dimension tables for consistent filtering and analysis.
  • RFM Metrics: Developed DAX calculations for purchase recency, distinct order frequency, and monetary spending.
  • Customer Scoring: Applied percentile thresholds and frequency-based rules to generate RFM scores from 1 to 4.
  • Customer Classification: Connected combined RFM scores to a segment lookup table.
  • Dashboard Development: Built customer segment charts, RFM score distributions, and customer-level tables.
  • Interactivity: Implemented slicers for gender, loyalty tier, income group, occupation, and education.

Data Modeling & Relationships

Designed a dimensional data model centered on the fact_sales table. The model connects sales transactions to customer, product, store, promotion, and date dimensions. A separate segmentation lookup table connects RFM score combinations to customer segment labels.

Central Fact Table

fact_sales stores transaction-level sales records, quantities, dates, and financial amounts.

Dimension Relationships

Customer, product, store, date, and promotion dimensions support filtering and analysis.

RFM Lookup

The segment table maps combined RFM scores to meaningful customer groups.

Modeling Approach

  • Organized transactional data separately from descriptive attributes.
  • Used one-to-many relationships from dimension keys to transaction records.
  • Linked dim_customer to fact_sales through customer_key.
  • Linked segment to dim_customer through the R-F-M classification key.
  • Used the date dimension to support consistent calendar-based analysis.

DAX Calculations & RFM Scoring

Implemented DAX expressions to derive customer-level purchase metrics, assign RFM scores, and translate those scores into customer segments. The following expressions are the core calculations relevant to this dashboard.

01. Last Purchase Date

Retrieves the most recent transaction date for each customer and serves as the starting point for Recency. 

DateLastPurchase =
CALCULATE(
    MAX(fact_sales[order_date])
)

02. Total Recency

Calculates elapsed days between a customer's last purchase and the reference date. Lower values indicate more recent purchasing activity. 

Total Recency =
DATEDIFF(
    dim_customer[DateLastPurchase],
    MAX(fact_sales[order_date]),
    DAY
)

03. Total Frequency

Uses DISTINCTCOUNT to count unique orders for each customer, preventing multiple sales line items from being treated as separate orders. 

Total Frequency =
CALCULATE(
    DISTINCTCOUNT(fact_sales[order_number])
)

04. Total Monetary

Aggregates each customer's spending using the sales_amount field. This metric supports identification of high-value customers. 

Total Monetary =
CALCULATE(
    SUM(fact_sales[sales_amount])
)

05. Recency Score

Applies percentile thresholds to assign Recency scores from 1 to 4. Customers with more recent purchases receive higher scores. 

Score Recency =
VAR percentile_25 =
    PERCENTILE.EXC(
        dim_customer[Total Recency], 0.25
    )
VAR percentile_50 =
    PERCENTILE.EXC(
        dim_customer[Total Recency], 0.5
    )
VAR percentile_75 =
    PERCENTILE.EXC(
        dim_customer[Total Recency], 0.75
    )

RETURN
IF(
    dim_customer[Total Recency] = BLANK(),
    BLANK(),
    IF(
        dim_customer[Total Recency] >= percentile_75,
        1,
        IF(
            dim_customer[Total Recency] >= percentile_50,
            2,
            IF(
                dim_customer[Total Recency] >= percentile_25,
                3,
                4
            )
        )
    )
)

06. Frequency Score

Assigns scores based on the number of distinct customer orders. A customer with four or more purchases receives the highest frequency score. 

Score Frequency =
IF(
    dim_customer[Total Frequency] >= 4, 4,
    IF(
        dim_customer[Total Frequency] >= 3, 3,
        IF(
            dim_customer[Total Frequency] >= 2, 2,
            IF(
                dim_customer[Total Frequency] >= 1,
                1,
                BLANK()
            )
        )
    )
)

07. Monetary Score

Uses the spending distribution to determine percentile thresholds. Higher-spending customers receive higher Monetary scores. 

Score Monetary =
VAR percentile_25 =
    PERCENTILE.EXC(
        dim_customer[Total Monetary], 0.25
    )
VAR percentile_50 =
    PERCENTILE.EXC(
        dim_customer[Total Monetary], 0.5
    )
VAR percentile_75 =
    PERCENTILE.EXC(
        dim_customer[Total Monetary], 0.75
    )

RETURN
IF(
    dim_customer[Total Monetary] = BLANK(),
    BLANK(),
    IF(
        dim_customer[Total Monetary] >= percentile_75,
        4,
        IF(
            dim_customer[Total Monetary] >= percentile_50,
            3,
            IF(
                dim_customer[Total Monetary] >= percentile_25,
                2,
                1
            )
        )
    )
)

08. Combined RFM Score

Combines the three individual scores into a single classification key, such as 4-3-4. This key is used to connect customers to the segmentation table. 

Score R-F-M =
    [Score Recency]
    & "-"
    & [Score Frequency]
    & "-"
    & [Score Monetary]

09. Customer Segment Classification

Retrieves the customer segment from the related lookup table. Customers without a matching segment are categorized as Other. 

Segment =
IF(
    RELATED(segment[Segment]) = BLANK(),
    "Other",
    RELATED(segment[Segment])
)

Technical Impact & Business Value

This project demonstrates how a structured data model and DAX-based analytics can transform raw transactions into customer-level segmentation and interactive business reporting.

Centralized Data Modeling

Connected sales transactions and descriptive dimensions into a reusable Power BI model, enabling consistent filtering across multiple attributes.

Automated Customer Scoring

Used DAX to calculate purchasing behavior metrics and translate RFM score combinations into customer groups, reducing reliance on manual segmentation calculations.

Interactive Analytics

Developed visualizations and demographic slicers that allow users to explore customer segments, RFM distributions, and individual customer records.

Marketing Decision Support

Created a segmentation framework that can help analysts and marketing teams prioritize customers for retention, repeat-purchase, and loyalty strategies.
